# 🐋 OrcaAI Chat

Нейросеть OrcaAI от OrcaAbyss — дружелюбный AI-ассистент с красивой анимацией печати.

## ✨ Возможности
- 💬 Умный чат с историей диалога
- 🎨 Эффект печати с размытием
- 🔄 Авто-выбор работающей модели
- 🌙 Тёмная тема
- 📱 Работает на телефоне

## 🛠 Технологии
- HTML, CSS, JavaScript
- OpenRouter API
- DeepSeek Chat
